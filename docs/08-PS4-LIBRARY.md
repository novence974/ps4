# تطبيق المكتبة على PS4 (تطبيق Homebrew مبني بـ OpenOrbis)

يعرض مكتبة الموقع على شاشة التلفاز ويُدار بيد التحكم. يعمل بلغة C مع أدوات OpenOrbis المفتوحة المصدر، ويرسم الواجهة بنفسه في ذاكرة العرض، ويتصل بالخادم عبر `/api/v1`. لا يحوّل تطبيق Android ولا يعتمد عليه.

> **تنبيه مهم:** هذه النسخة **لم تُبنَ حزمة PKG منها هنا ولم تُشغَّل على جهاز PS4**. انظر «ما الذي اختُبر» قبل التجربة.

## ما يفعله وما لا يفعله

| يفعل | لا يفعل |
|---|---|
| تصفح الألعاب حسب الجهاز (PS1–PS5) مع الترتيب، والبحث بلوحة مفاتيح على الشاشة (عربي وإنجليزي ورموز) | **لا ينزّل الألعاب ولا يثبّتها**، ولا يتعامل مع ملفات اللعبة إطلاقاً |
| صفحة اللعبة: الغلاف والخلفية، والبيانات، والوصف، والإصدارات، والتوافق، وقائمة الملفات (الاسم والحجم ومن يحق له التنزيل)، ورابط صفحتها على الموقع | لا يتجاوز أي حماية أو توقيع أو DRM |
| الأخبار، والمفضلة والإشعارات لحساب مسجّل، وتسجيل الدخول والخروج | لا يعمل على PS5 ولا PS3، ولا على أجهزة PS4 العادية |

تُنزَّل الملفات من الموقع فقط، بعد تحقق الخادم من صلاحية الحساب كما في المرحلة الأولى.

### متطلبات الجهاز

الحزمة تطبيق Homebrew غير موقّع من Sony. يمكن تثبيتها فقط على جهاز PS4 مفعّل عليه تشغيل تطبيقات Homebrew مع مثبّت حزم. تفعيل ذلك خارج نطاق هذا المشروع، ولا نقدم أدواته أو خطواته.

## البناء

تحتاج:

1. **OpenOrbis PS4 Toolchain** من صفحة الإصدارات (Releases) على GitHub. استخدم ملف الإصدار المضغوط، وليس نسخة git المجردة، لأن الأخيرة لا تحتوي الأدوات والمكتبات المبنية.
2. **clang** و**ld.lld**، الإصدار 12 أو أحدث (مثلاً: `sudo apt install clang lld`).
3. بحسب إصدار الأدوات، قد يحتاج `PkgTool.Core` إلى .NET runtime. راجع README الخاص بالأدوات.

```bash
cd clients/ps4-library
export OO_PS4_TOOLCHAIN=/opt/OpenOrbis/PS4Toolchain
make SERVER_URL=https://library.example.com
```

ينتج الأمر:

- `eboot.bin`
- `sce_sys/param.sfo`
- الحزمة `IV0000-UPSL00001_00-UPSLLIBRARY00000.pkg`

`SERVER_URL` هو عنوان الخادم الافتراضي داخل الحزمة، ويمكن تغييره لاحقاً من إعدادات التطبيق. على Windows استخدم WSL. ملف `Makefile` يتبع قالب أمثلة OpenOrbis نفسه.

### معلومات الحزمة

| الحقل | القيمة |
|---|---|
| TITLE | ULTIMATE PS LIBRARY |
| TITLE_ID | `UPSL00001` |
| CONTENT_ID | `IV0000-UPSL00001_00-UPSLLIBRARY00000` |
| الإصدار | 1.00 |
| المكتبات | `libSceVideoOut` و`libScePad` و`libSceUserService` و`libSceSystemService` و`libSceSysmodule` و`libSceNet` و`libSceSsl` و`libSceHttp` |

## أول تشغيل

1. إن لم يُضبط عنوان عند البناء، تُفتح لوحة المفاتيح لكتابة عنوان الخادم (مثل `https://library.example.com`).
2. يتصل التطبيق ويعرض الأجهزة والألعاب. التصفح والبحث والأخبار لا تحتاج حساباً.
3. **المفضلة والإشعارات** تحتاج تسجيل الدخول من «الإعدادات ← الحساب»، أو بالضغط على X عند فتحهما. استخدم **حساب مكتبة عادياً، لا حساب مدير**.

## التحكم

| الزر | الوظيفة |
|---|---|
| الأسهم / العصا اليسرى | التنقل (مع تكرار عند الضغط المستمر) |
| X | فتح / اختيار / إضافة للمفضلة في صفحة اللعبة |
| O | رجوع / إلغاء |
| L2 / R2 | التنقل بين الأقسام: المكتبة، بحث، الأخبار، المفضلة، الإشعارات، الإعدادات |
| L1 / R1 | تغيير الجهاز في المكتبة؛ اللعبة السابقة/التالية في صفحة اللعبة |
| المربع | تغيير الترتيب (الأحدث، الأكثر تنزيلاً، الأعلى تقييماً، الاسم) |
| المثلث | فتح البحث؛ تحديث الأخبار والإشعارات |
| OPTIONS | الإعدادات؛ و«تم» في لوحة المفاتيح |

في لوحة المفاتيح:

- X يكتب الحرف المحدد.
- المربع يحذف حرفاً.
- المثلث يضيف مسافة.
- R1 يغيّر اللغة بين abc وABC و#+= والعربية.

## الأمان والخصوصية

- يتحقق الاتصال عبر HTTPS من شهادة الخادم بمخزن شهادات الجهاز، ولا يُتجاوز هذا الفحص أبداً. إذا ظهر خطأ `send error 0x…` فالجهاز لا يثق بشهادة الخادم: استخدم شهادة من جهة معروفة، أو اختبر عبر `http://` على شبكتك المحلية فقط.
- يُحفظ عنوان الخادم ورمز الدخول في `/data/upsl-library/settings.json` على الجهاز. لا توجد على PS4 خزنة مفاتيح متاحة لتطبيقات Homebrew، ومن يصل إلى ملفات الجهاز يستطيع قراءة الرمز. لذلك:
  - استخدم حساباً عادياً.
  - سجّل الخروج من «الإعدادات ← الحساب» عند الحاجة، أو ألغِ رمز «PlayStation 4» من «أجهزتي» في الموقع.
- لا تُحفظ كلمة المرور. تُمحى من الذاكرة بعد تسجيل الدخول.

## العربية على الشاشة

يرسم التطبيق النصوص بخط **Readex Pro**، الخط نفسه المستخدم في الموقع، عبر stb_truetype.

- **ربط الحروف العربية:** تُستخرج أشكال كل حرف (أول الكلمة، ووسطها، وآخرها، ومنفصلاً) وأشكال «لا» من جداول الخط نفسه (OpenType GSUB) إلى `src/arabic_forms.h`، بالسكربت `tools/gen_arabic_forms.py`.
- **اتجاه النص:** خوارزمية اتجاه مبسطة ترتب العربية والإنجليزية والأرقام في السطر الواحد.
- **حدود معروفة:** لا تُحاذى علامات التشكيل بدقة، ولا تدعم الخوارزمية الحالات المعقدة من خوارزمية Unicode Bidi. هذا يكفي لعناوين الواجهة والأوصاف العادية.

إذا غيّرت الخط، أعد توليد جدول أشكال الحروف:

```bash
python3 tools/gen_arabic_forms.py assets/fonts/readex_regular.ttf src/arabic_forms.h
```

الخطّان (العادي والعريض) يشتركان في ترتيب الحروف نفسه، فالجدول واحد لهما.

## ما الذي اختُبر (وما الذي لم يُختبر)

| الاختبار | النتيجة |
|---|---|
| **نسخة سطح المكتب** (`make desktop`): كود التطبيق نفسه يعمل على Linux بذاكرة عرض 1920×1080، وبيد تحكم مبرمجة، واتصال HTTP، ضد الخادم الحي. المسار المختبر: المكتبة، والتنقل، وتغيير الجهاز، وصفحة اللعبة والتمرير، والترتيب، ولوحة المفاتيح والبحث، والأخبار، والمفضلة دون حساب، ثم تسجيل الدخول، والمفضلة بعده، والإشعارات، والإعدادات، وتسجيل الخروج | ✓ ‏16 لقطة في `clients/ps4-library/screenshots/` |
| فحص أنواع الكود الخاص بـ PS4 (`main_ps4.c`) بـ clang مقابل ترويسات OpenOrbis | ✓ بلا أخطاء. الفحص استخدم ترويسات C الخاصة بـ Linux، وليس بناءً حقيقياً بأدوات OpenOrbis |
| **البناء بأدوات OpenOrbis وإنتاج PKG** | ✗ **لم يُنفّذ هنا**، فبيئة التطوير لا تسمح بتشغيل أدوات OpenOrbis المبنية مسبقاً. **لا توجد حزمة PKG مرفقة** |
| **التشغيل على جهاز PS4** | ✗ لم يُجرَّب. أجزاء تعتمد على الجهاز وحده لم تُختبر: VideoOut وتبديل الإطارات، وقراءة يد التحكم، وlibSceHttp وشهادات HTTPS، والحفظ في `/data` |

أرسل لنا نتيجة أول بناء ونص أي خطأ يظهر. إذا بنيت الحزمة وشغّلتها، صوّر الشاشة عند أي مشكلة في الرسم أو الاتصال.

## الملفات

| الملف | الوصف |
|---|---|
| `src/app.c` | الشاشات والتنقل والبيانات (مشترك بين PS4 وسطح المكتب) |
| `src/main_ps4.c` | طبقة PS4: العرض، ويد التحكم، وHTTP عبر libSceHttp |
| `src/main_desktop.c` | نسخة الاختبار على Linux (ليست جزءاً من الحزمة) |
| `src/api.c`، `src/json.c` | عميل واجهة API وقارئ JSON |
| `src/gfx.c`، `src/text.c`، `src/image.c` | الرسم، والنصوص والعربية، والصور (JPEG/PNG بنسخة `sm_jpg` من الخادم) |
| `tests/run_desktop.sh` | تشغيل مسار الاختبار وحفظ اللقطات |

## التراخيص

- خط **Readex Pro**: رخصة SIL OFL 1.1.
- **stb_truetype** و**stb_image** و**stb_image_write**: ملكية عامة أو رخصة MIT (الملفات في `src/` كما هي).
- **OpenOrbis PS4 Toolchain**: أداة بناء خارجية، ولا يُضمَّن منها شيء في هذا المجلد.
