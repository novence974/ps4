# ULTIMATE PS LIBRARY

مكتبة ألعاب PlayStation (من PS1 إلى PS5) بواجهة زجاجية داكنة وفاتحة، ولوحة تحكم كاملة، وواجهة REST موحّدة
(`/api/v1`) يتصل بها تطبيق الإدارة على Android، وسيتصل بها تطبيق PS4.

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1 | موقع PHP + لوحة التحكم + قاعدة البيانات + API + الرفع المجزأ + الاختبارات + التوثيق | **مكتملة ومختبرة** (هذه الحزمة) |
| 2 | تطبيق الإدارة على Android (مشروع Sketchware Pro بصيغة SWB) في `clients/android-admin` | **مكتمل**: مختبر بالترجمة وفحص الـ SWB واختبارات JVM وRobolectric ضد الخادم؛ لم يُجرَّب بعد داخل Sketchware Pro ولا على هاتف — انظر [docs/07-ANDROID-ADMIN.md](docs/07-ANDROID-ADMIN.md) |
| 3 | تطبيق مكتبة PS4 (Homebrew بـ OpenOrbis) في `clients/ps4-library` | **المصدر وملفات البناء جاهزة**: الكود نفسه مختبر على Linux ضد الخادم مع 16 لقطة شاشة. **لم تُبنَ حزمة PKG هنا ولم يُشغَّل على PS4** — انظر [docs/08-PS4-LIBRARY.md](docs/08-PS4-LIBRARY.md) |
| 4 | النشر على GitHub: Pages للصفحات العامة، وCodespaces وDocker للموقع الكامل | **جاهز**: التصدير الثابت وDocker مختبران هنا؛ الـ workflow لم يُشغَّل على GitHub بعد — انظر [docs/09-GITHUB.md](docs/09-GITHUB.md) |

لا تحتوي هذه الحزمة على أي ملف PKG، ولا ندّعي وجوده؛ يُبنى بالأمر `make` على جهاز فيه أدوات OpenOrbis، والخطوات في [docs/08-PS4-LIBRARY.md](docs/08-PS4-LIBRARY.md).

## ما الذي يعمل الآن

- **الموقع العام:** الرئيسية، الأجهزة الخمسة، التصفح، التصنيفات الاثنا عشر، صفحة اللعبة (صور، فيديو، إصدارات، ملفات، توافق)، التحديثات، البحث الفوري، وفلاتر الجهاز والتصنيف والسنة والشركة واللغة والمنطقة والحجم والتقييم وتاريخ الإضافة وتوفر الملفات، مع الترتيب حسب الأحدث أو الأعلى تقييماً أو الأكثر تنزيلاً أو الاسم أو السنة.
- **الحسابات:** تسجيل وتأكيد بريد واستعادة كلمة مرور، وأربعة أدوار (مدير رئيسي، مدير، مشرف مكتبة، مستخدم)، و26 صلاحية قابلة للتعديل، ومفضلة وسجل مشاهدة وسجل تنزيلات وإشعارات وإدارة الأجهزة المتصلة.
- **لوحة التحكم:** كل الصفحات المطلوبة في المواصفات (لوحة المعلومات، الألعاب، الأجهزة، التصنيفات، المستخدمون، مدير الرفع، التنزيلات، التحديثات، التخزين، إعدادات API، الأمان، سجل النشاط، النسخ الاحتياطي والاستعادة)، إضافة إلى الاستيراد بالجملة CSV/JSON وكشف الألعاب المكررة والإشعارات والأدوار.
- **الرفع:** رفع مجزأ (5 ميغابايت افتراضياً) مع إيقاف واستكمال، واستئناف تلقائي بعد انقطاع الشبكة، وتحقق SHA-256 لكل جزء وللملف كاملاً، وعرض السرعة والمتبقي، وتجميع الملفات الكبيرة في الخلفية. الملفات تُحفظ على القرص، وقاعدة البيانات تحفظ بياناتها ومساراتها فقط.
- **التنزيل:** روابط موقّعة مؤقتة، ودعم طلبات Range (استكمال التنزيل)، وفحص الصلاحية عند كل طلب، ومدير تنزيلات في المتصفح بإيقاف واستكمال ومطابقة SHA-256. يدعم اختيارياً X-Accel-Redirect في nginx و X-Sendfile في Apache.
- **التصميم:** زجاجي بخلفيات داكنة وألوان بنفسجي وأزرق وسماوي، مع وضع فاتح، ويتكيف مع الجوال والجهاز اللوحي والتلفاز (تنقل بالأسهم ويد التحكم في وضع TV).
- **الموسيقى:** مقطوعة أصلية لا تعمل قبل تفاعل الزائر، وتُحفظ حالتها ومستوى صوتها، إضافة إلى مؤثرات صوتية قصيرة قابلة للإيقاف.

## تشغيل سريع

المتطلبات: PHP 8.2 أو أحدث (pdo_mysql، gd مع دعم WebP، mbstring، fileinfo، curl)، و MySQL 8.0+ أو MariaDB 10.5+، و nginx أو Apache. Redis اختياري ومُستحسن.

```bash
cd server
php bin/install.php --db-host=127.0.0.1 --db-name=upsl --db-user=upsl --db-pass='…' \
  --url=https://library.example.com --admin-user=admin --admin-email=you@example.com \
  --admin-pass='Strong-Pass-2026' --demo --timezone=Asia/Riyadh
# ثم أضف إلى crontab:
# * * * * * php /path/to/server/bin/cron.php >> /path/to/server/storage/logs/cron.log 2>&1
```

أو افتح `https://موقعك/install.php` لاستخدام معالج التثبيت. الخطوات التفصيلية لكل خادم في [docs/01-INSTALL.md](docs/01-INSTALL.md).

```
  deploy/                 nginx.conf، apache-vhost.conf، php.ini مقترح، crontab، خدمة systemd للعامل

  tests/                  run.php (API والأمان)، perf.php (الأداء)، e2e/ (متصفح Chrome حقيقي)
tools/                    سكربتات Python التي ولّدت الشعارات والأغلفة والموسيقى الأصلية
```

## نتائج الاختبار

جرت كل الاختبارات على خوادم حقيقية بعد تثبيت نظيف بالبيانات التجريبية، والتفاصيل في [docs/05-TESTING.md](docs/05-TESTING.md):

- **80 اختبار API وأمان:** نجحت كلها على nginx + PHP-FPM 8.3، وعلى Apache 2.4 بجذر `public/`، ومع كاش الملفات بدل Redis. وعلى Apache بجذر المشروع كاملاً (حالة الاستضافة المشتركة) نجحت اختبارات الأمان والصفحات والتنزيل.
- **4 اختبارات متصفح في Chrome حقيقي:** رفع 24 ميغابايت مع إيقاف وانقطاع شبكة، وتنزيل مع استكمال ومطابقة SHA-256، ومنع التشغيل التلقائي للموسيقى، والتنقل بالريموت في وضع التلفاز. نجحت كلها.
- **الأداء مع 5,030 لعبة و16 طلباً متزامناً على معالج بنواتين:**
  - قائمة الألعاب: نحو 870 طلباً في الثانية، و p95 = 47 ms.
  - البحث النصي بعبارات غير مكررة (بدون كاش): p50 = 106 ms.
  - الصفحة الرئيسية: p95 = 48 ms.
  - لا أخطاء في أي سيناريو.
- **فحص الروابط:** 219 صفحة (زائر ومدير) بلا أي رابط معطل.

## ملاحظات قانونية وتقنية مهمة

- المنظومة تدير **ملفات مصرّح بها فقط**. كل تنزيل يمر بفحص صلاحيات المستخدم ومستوى الوصول للملف.
- لا يوجد أي تجاوز لحماية الأجهزة أو التوقيعات أو إدارة الحقوق الرقمية، ولا يوجد ادعاء بأن تثبيت الألعاب مدعوم على كل أجهزة PlayStation. صفحات الأجهزة تعرض الصيغ والطرق الرسمية فقط.
- الألعاب التجريبية الـ31 خيالية، وأغلفتها وصورها وشعارات الأجهزة النصية والموسيقى أصلية ولّدتها سكربتات `tools/`، ولا تستخدم أي علامة تجارية أو شعار رسمي.
- المكونات الخارجية المضمّنة وتراخيصها:
  - خط Readex Pro (SIL OFL 1.1).
  - أيقونات Lucide (ISC).
  - hash-wasm (MIT).
  
  النصوص الكاملة للتراخيص في `server/public/assets/vendor/LICENSES.txt`.
